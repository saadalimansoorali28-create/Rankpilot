What should a title tag do?

A title should clearly describe the page and help users understand the result before they click. Keep it accurate and avoid repetitive keyword stuffing.

Write a useful meta description

Summarize the page honestly and give the searcher a reason to understand its value. Treat the description as a useful snippet suggestion rather than a guaranteed search-result text.

Don't forget canonical URLs

For pages that need canonicalization, use the preferred absolute URL and keep internal links consistent with it.
