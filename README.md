# RankPilot

RankPilot is a lightweight, SEO-focused tools website for keyword research, YouTube SEO, and website optimization.

## Current stack
- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- GitHub Pages-ready static deployment
- SEO basics: title, description, canonical, Open Graph, robots.txt, sitemap.xml
- Client-side starter tools for keyword ideas, YouTube optimization, meta tags, keyword density, and sitemap generation

## Planned expansion
- Real keyword data integrations
- YouTube title/description/tag analysis
- Full website SEO crawler
- SERP utilities
- On-page SEO helpers
- SEO guides and educational content
