Meta Tags SEO Guide

Metadata gives search engines and other systems important information about a page. The most useful metadata is accurate, consistent, and aligned with the visible content.

Title tag

Use a concise, descriptive title that reflects the page's main subject. Avoid stuffing several unrelated phrases into it.

Meta description

Write a useful summary that can help a searcher understand the page. Search engines may choose different snippet text depending on the query.

Canonical URL

Use a canonical link when you need to indicate a preferred URL among substantially duplicate or similar versions.

Robots directives

Use robots directives deliberately. Do not add noindex to a page you want search engines to index.

Open Graph

Open Graph metadata can improve how a page is represented when shared on compatible social platforms. Keep the title and description consistent with the page.
